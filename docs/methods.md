# Pipeline contract

Preparation splits biological samples before selecting genes, fitting time coordinates, or training any model. A sample has one time and one matching-stratum assignment. Gene selection ranks training expression variance, with stable ties, and preserves input gene order. This is a simple variance panel, not an implementation of a named Scanpy HVG flavor. Users can supply a preselected panel and set `n_genes: null`.

Count MSE representations use library-total normalization against the original full input panel followed by log1p. The checkpoint stores that panel so extra inference genes cannot change normalization. Processed `log1p` inputs pass through unchanged; preprocessing outside the pipeline must use the same convention during fitting and inference. NB representations retain raw counts, encode log1p counts, and use a softplus count mean and learned gene dispersion. Predicted means are not observed counts or biological replicates.

The default GMVAE uses a learned Gaussian-mixture prior and Monte Carlo KL term. The VAE uses a standard Gaussian prior. The representation trains once and is frozen for all transport training. The extracted model definitions and source file hashes are recorded in [source_receipt.json](source_receipt.json).

Transport has the identity-preserving form `F(s,t,z) = z + (t-s) phi(s,t,z)`. Cell-type-conditioned transport uses a shared input adapter/trunk plus per-type drift heads initialized at zero. Model time is `(observed_time - origin) / scale`. The default origin and scale are the training minimum and range. Set both explicit values to use another coordinate, for example origin 0 and scale 100. The checkpoint's coordinates are always used for generation and localization; they are never refitted to target data.

Training constructs populations by biological sample or by observed time, within configured strata and cell type. Each step selects a family uniformly, then two distinct times uniformly, then a sample uniformly within each time. Cell batches are capped. Bidirectional training permits either direction. Gene-space Sinkhorn loss compares decoded transport to observed target expression; latent Sinkhorn compares transported states to target latent means. Optional endpoint consistency compares independent source populations transported to the same endpoint. It applies when an additional eligible source population exists; it is skipped when the family has only the selected source and target populations. The training weights describe available terms, rather than guaranteeing support for every term in every step.

Validation selection uses one known-time expression Sinkhorn score per heldout sample/population, averaged equally. For each validation population, the closest matching training population at a different time supplies source cells. This prevents same-time identity reconstruction from replacing a transport-selection score. Selection uses the lowest validation score; ties keep the earlier epoch. The default selection criterion is different from the report's later internal localization-MAE selection. With `selection: last`, validation samples remain excluded and the final epoch is retained. Test samples participate in neither stage. The model artifact records the actual criterion and selected epoch.

Localization chooses source-time pools entirely from training references matched on strata and, for conditioned flows, cell type. It searches the user-specified common candidate grid in latent Sinkhorn distance without reading target time labels. Seeded ties do not use truth labels. It averages source-time predictions within each target sample/population. A requested source set must be complete; insufficient source support or target cells produce a status row without an inferred time. Bounded stored reference cells make checkpoint inference possible without the original training file. Reference cells are capped per training population, so changing that cap changes inference support.

Known-time generation decodes transported source cells at an explicit requested time. Localization and generation are separate operations. Reconstruction evaluation compares generation from the earliest eligible training source time against observed target means. Its source-population means receive equal weight. Reported metrics are descriptive. The pipeline does not infer DE significance from generated cells, compute confidence intervals by treating cells as donors, or claim independent biological replication from synthetic examples.

Training expression is densified only in batches. Latent encodings remain on CPU and references are capped per population. AnnData is loaded in memory by the CLI, and generated output allocates a selected-gene matrix. Large datasets still require enough host memory for the input, latent encodings, and requested output. Tensorized Sinkhorn has quadratic cell-batch memory; reduce `cell_batch_size`, localization `max_cells`, or `max_reference_cells` as appropriate.

The compact pipeline deliberately omits historical comparator backends, disease/control calibration, paper plotting, dataset-specific source selection, edgeR orchestration, Slurm launchers, joint representation updates, LSD, EMA-teacher inference, and archived ablation options. It fits new-format self-contained checkpoints. Historical research checkpoints are not automatically interchangeable with this format, and this package does not promise to regenerate historical paper metrics.
